# Protocolo policial con adolescentes · Ley 27.801 (Tucumán)

Guía de bolsillo para el personal policial: actuación con adolescentes de 14 a 17 años según la Ley Nacional 27.801, la Ley Provincial 10.011 y el CPP de Tucumán.

**Ver la guía:** https://sergioponce88.github.io/protocolo-policial-ley27801/

Incluye: ruta del procedimiento (lugar del hecho → comunicaciones → sujeción → centro asistencial → CAD), reglas, 34 casos con buscador, tareas del suboficial y del oficial, quién es quién, lista de control y síntesis antes/ahora.

> Actualmente no existe un protocolo oficial del MPF Tucumán. Esta guía sigue las directivas de Jefatura de Policía.
